Бокал — не только посуда. Форма управляет ароматом, скоростью нагрева и даже ощущением вкуса. Разбираем базу.

## Основные формы

- **Рокс (стакан)** — для виски, негазированных коктейлей со льдом.
- **Хайбол** — высокий, для тоника, мохито, лонг-дринков.
- **Коктейльный (мартинка)** — V-образный, для Мартини, Дайкири.
- **Флюте** — узкий, для игристого и шампанского.
- **Бокал для вина** — для красного/белого.
- **Пивной** — для крафта.
- **Шот** — 30–50 мл, для стопок.
- **Снифтер** — для коньяка/бренди.

## Почему форма важна

Узкие бокалы концентрируют аромат (флюте, снифтер), широкие — раскрывают (вино). Край направляет поток жидкости на разные зоны языка.
